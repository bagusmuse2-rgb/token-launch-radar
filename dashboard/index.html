How the implied value is built

One function scores every protocol, from the snapshot's own figures only. No name is special-cased, and nothing here predicts whether — or when — a token launches.

  1. BaseTVL × base multipleSize today, at the base multiple.
  2. Growth7-day change, clamped to a floor and a cap, weighted × growth weightMomentum lifts or drags the base.
  3. Maturitymaturity floor + age up to maturity cap days × maturity rangeLonger running with no token counts for more.

implied = round( tvl_usd × base × (1 + clamped 7d change × weight) × maturity )

Implied value is the model's claim, not a price and not a promise. A protocol that records no token may still have one its record does not carry.
